# Handoff and release

A handoff must include:

- summary of the behavior and reason for the change;
- changed files and any generated artifacts;
- commands run, exit status, and meaningful results;
- known limitations, blocked checks, and residual risk;
- migration, rollback, or release notes when applicable.

Before release, inspect the diff, verify no secrets or unrelated files are included, and ensure policy changes received independent review. Do not claim release or deployment without evidence of the requested target.
